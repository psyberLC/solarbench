# Asset licences and sources

Every asset here is generated by [`scripts/build_assets.py`](../scripts/build_assets.py) from the values in [`solarbench/specs`](../solarbench/specs). Geometry is authored from published dimensions; textures are procedural. No manufacturer's CAD file, mesh, image or logo is included.

| Asset | What it models | Numbers taken from | Licence |
|---|---|---|---|
| `longi_lr7_72hvd` | 2382 × 1134 × 30 mm, 33.5 kg glass-glass PV module | Manufacturer's datasheet and installation manual | CC-BY-4.0 |
| `jinko_72hl4r` | 2335 × 1134 × 35 mm, 28.5 kg glass-backsheet PV module | Manufacturer's datasheet | CC-BY-4.0 |
| `fixed_tilt_table_1p` | One-portrait fixed-tilt table, 20°, 0.6 m lower edge | Mounting-system manufacturers' published ranges | CC-BY-4.0 |
| `mc4_male`, `mc4_female` | PV connector pair with latch geometry | IEC 62852 and manufacturer's data; clearance and chamfer assumed | CC-BY-4.0 |
| `end_clamp_m8` | Module end clamp with an M8 hex bolt | DIN 933; torque window from the module manual | CC-BY-4.0 |
| `husky_a300_parked` | Outline of a parked mobile base with an arm mount | Manufacturer's datasheet dimensions | CC-BY-4.0 |
| `scenes/` | Plant scenery for rendering only | Derived from the table and module specs | CC-BY-4.0 |

The source for each number is in [docs/sources.md](../docs/sources.md); anything assumed is in [ASSUMPTIONS.md](../ASSUMPTIONS.md).

## Not included
Robot models are downloaded at run time from NVIDIA's Isaac asset server and stay under the terms published there. Building them from openly licensed descriptions, so that nothing is fetched at run time, is the board item `infra-open-robots`.

## Names
Product and manufacturer names identify the datasheet a model was built from. They imply no affiliation or endorsement.
